# King Döner

Diese Website wurde automatisch mit dem AI Website Generator erstellt.

## Nutzung

Öffne einfach die Datei `index.html` in deinem Browser – es sind
keine weiteren Installationsschritte nötig.

## Struktur

```
King Döner/
  index.html      -> Die vollständige Website (HTML + eingebettetes CSS)
  assets/         -> Platz für eigene Bilder, Logos, etc.
  favicon.ico     -> Platzhalter-Favicon
```

## Hinweise

- Bilder sind aktuell Platzhalter (placehold.co). Ersetze sie in
  `index.html` durch eigene Bilder aus dem `assets/`-Ordner.
- Das Kontaktformular ist rein statisch. Für echte Funktionalität
  muss ein Backend (z. B. Formspree, ein eigener Mailserver, etc.)
  angebunden werden.
- Impressum und Datenschutz enthalten Platzhaltertexte und müssen
  vor dem Live-Gang rechtssicher ausgefüllt werden.
